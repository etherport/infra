# Kubespray Configuration

Kubernetes cluster deployment and management using [Kubespray](https://github.com/kubernetes-sigs/kubespray).

## Directory Structure

```
kubespray/
├── setup.sh              # One-time setup script
├── kubespray.sh          # Wrapper for running playbooks
├── kubespray/            # Kubespray submodule (git-tracked)
└── inventory/            # Cluster configuration
    ├── inventory.ini     → symlink → ../../ansible/inventory/wind/inventory.ini
    │                       (single source of truth shared with the homelab
    │                        ansible playbooks; standalone-VM entries there
    │                        are ignored by kubespray's k8s_cluster group)
    ├── group_vars/       # Kubespray-specific variable definitions
    │   ├── all/          # Global variables (cluster-level)
    │   └── k8s_cluster/  # k8s-cluster-specific
    └── pre-flight.yml    # Pre-flight checks
```

## Quick Start

### Initial Setup (one time)

```bash
cd ~/Projects/homelab-infra/infra/kubespray
./setup.sh
```

This will:
1. Initialize the kubespray submodule
2. Create a Python virtual environment
3. Install dependencies
4. Symlink your inventory

### Running Playbooks

Use the wrapper script:

```bash
cd ~/Projects/homelab-infra/infra/kubespray

# Deploy or update cluster
./kubespray.sh cluster.yml

# Upgrade Kubernetes version
./kubespray.sh upgrade-cluster.yml

# Upgrade single node
./kubespray.sh upgrade-cluster.yml --limit k8s-w1

# Add new nodes
./kubespray.sh scale.yml

# Remove a node
./kubespray.sh remove-node.yml -e node=k8s-w3

# Dry run
./kubespray.sh cluster.yml --check --diff
```

Or manually:

```bash
cd ~/Projects/homelab-infra/infra/kubespray/kubespray
source venv/bin/activate
# Inventory is now a single file at the kubespray dir root:
# infra/kubespray/inventory/inventory.ini  (the wrapper symlinks/passes
# this in for you). Legacy `inventory/wind/` paths no longer exist.
ansible-playbook -i ../inventory/inventory.ini cluster.yml --become
```

## Common Tasks

### Upgrade Kubernetes Version

1. Edit the version:
   ```bash
   vim inventory/group_vars/k8s_cluster/k8s-cluster.yml
   # Change: kube_version: v1.33.8
   ```

2. Run upgrade:
   ```bash
   ./kubespray.sh upgrade-cluster.yml
   ```

### Add a New Node

1. Add to inventory:
   ```bash
   vim inventory/inventory.ini
   # Add new node under [all] and [kube_node]
   ```

2. Run scale:
   ```bash
   ./kubespray.sh scale.yml
   ```

### Remove a Node

```bash
# Drain first
kubectl drain k8s-w3 --ignore-daemonsets --delete-emptydir-data

# Remove via kubespray
./kubespray.sh remove-node.yml -e node=k8s-w3

# Delete from Kubernetes
kubectl delete node k8s-w3

# Update inventory
vim inventory/inventory.ini
```

## Updating Kubespray

```bash
cd kubespray
git fetch origin
git checkout v2.27.0  # Or desired version
cd ..
./setup.sh  # Reinstall dependencies if needed
```

## Sensitive Files

These are generated by kubespray but gitignored:

- `inventory/artifacts/admin.conf` - Kubernetes admin kubeconfig
- `inventory/credentials/` - Certificate keys

To retrieve admin.conf after cluster changes:
```bash
scp -i /tmp/auto-key ubuntu@k8s-cp1:/etc/kubernetes/admin.conf ~/.kube/config
```

## Troubleshooting

### SSH Connection Issues

```bash
# Test connectivity
ansible -i inventory/inventory.ini all -m ping

# Verbose mode
./kubespray.sh cluster.yml -vvv
```

### Partial Failures

```bash
# Resume from specific task
./kubespray.sh cluster.yml --start-at-task="task name"

# Target specific node
./kubespray.sh cluster.yml --limit k8s-w1
```
